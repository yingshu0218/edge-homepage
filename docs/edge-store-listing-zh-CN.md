# Microsoft Edge 加载项商店资料（zh-CN）

## 基本信息

- 名称：Day Start
- 类别：生产力
- 简短说明：一个专注、可定制、支持跨设备同步的 Edge 新标签页。
- 支持页面：https://github.com/yingshu0218/edge-homepage/issues
- 隐私政策：https://github.com/yingshu0218/edge-homepage/blob/main/PRIVACY.md

## 单一用途说明

Day Start 用一个本地优先、可定制的新标签页替换 Edge 默认新标签页，让用户集中管理常用书签、搜索、时间、主题和天气信息。

## 详细说明

Day Start 为 Microsoft Edge 提供清爽、专注且可定制的新标签页。

主要功能：

- 分组管理常用书签，支持新增、编辑、删除、搜索、批量移动和独立排序；
- 可选择 Google、Bing、DuckDuckGo、百度等常用搜索引擎；
- 六套内置图片主题，支持深浅模式、遮罩、模糊和本地自定义背景；
- 使用设备本地时间，可选择 12/24 小时制、秒数和完整日期；
- 显示城市天气、未来小时预报和五日预报，可由用户主动授权当前位置；
- 书签、分组和设置先保存在本机，并通过 Edge 原生同步存储跨设备合并；
- 支持 JSON 导出、替换导入和合并导入，方便手动备份与迁移。

Day Start 不包含广告和分析工具，不读取浏览器原有收藏夹或浏览历史。书签、分组和设置优先保存在当前设备，并可由 Edge 同步；打开统计、最近常用记录、自定义背景和缓存仅保存在本机。

## 权限说明

- `storage`：在本机保存用户创建的书签、分组、设置和缓存，并通过 Edge 同步存储同步书签、分组及设置。
- `unlimitedStorage`：保存自定义背景和图标等本地资源，避免普通存储配额导致数据丢失。
- `geolocation`：仅在用户点击“使用当前位置”并授权后取得坐标，用于显示当地天气。
- `favicon`：通过浏览器提供的接口显示用户添加网站的图标。
- `https://geocoding-api.open-meteo.com/*`：根据用户输入搜索城市。
- `https://api.open-meteo.com/*`：根据选定城市坐标获取天气数据。
- `https://api.bigdatacloud.net/*`：仅在用户主动使用当前位置时，把坐标解析为城市名称。

### 主机权限理由（Partner Center 单独字段）

Day Start 需要访问清单中列出的三个精确天气服务主机，以便扩展的新标签页发起跨域网络请求：访问 `geocoding-api.open-meteo.com` 将用户输入的城市名称转换为候选城市和坐标；访问 `api.open-meteo.com` 根据用户选定的城市坐标获取当前天气、小时预报和五日预报；仅在用户主动点击“使用当前位置”并授权定位后，访问 `api.bigdatacloud.net` 将设备坐标解析为可显示的城市名称。这些主机权限只用于天气功能，不会读取或修改用户访问的网页，不会注入内容脚本，也不会访问未在清单中声明的其他网站。

## 远程代码

否。扩展为 Manifest V3，所有可执行代码均包含在提交的安装包中。远程服务仅返回城市和天气数据，不下载或执行远程代码。

## 数据使用披露

扩展会在用户主动使用天气功能时处理城市查询、城市坐标或设备当前位置。当前位置只在用户明确点击并授权后发送给 Open-Meteo 和 BigDataCloud，用于天气查询和城市解析。书签、分组和设置写入 Edge 提供的同步存储，用于在用户已开启同步的同账号 Edge 设备间传输；扩展不读取账号身份，也不使用自建同步服务器。扩展不持续追踪位置，不保存位置历史，不出售数据，不用于广告或与核心功能无关的用途。

## 审核测试说明

1. 安装后打开一个新标签页，确认 Day Start 替换默认新标签页。
2. 点击“添加书签”可创建书签；“管理书签”和“管理排序”可编辑、批量管理和排序。
3. 首页输入书签标题、网址或缩写可跨分组查找书签；用 ↑↓ 选择并按 Enter 打开。未选择书签时保留网页搜索和网址直达，搜索引擎可在设置中切换。
4. 点击右上角主题按钮可切换内置主题或选择本地背景。
5. 点击天气入口，在城市搜索框输入“厦门”并选择结果，即可查看天气；无需登录。
6. “使用当前位置”为可选功能，只有点击后才会触发 Edge 定位授权。
7. 设置中可导出 JSON，也可选择替换或合并方式导入。
8. 登录同一 Edge 账号并开启同步后，可在另一台安装 Day Start 的设备验证书签、分组和设置同步；无需向开发者提供测试账号。

扩展没有自建测试账号、付费功能或隐藏功能。天气服务需要网络连接；拒绝定位权限不会影响手动搜索城市及其他功能。Edge 跨设备同步由浏览器账号和同步设置控制。
