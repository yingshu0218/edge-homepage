# 在 Microsoft Edge 中安装 Day Start

## 1. 生成扩展目录

在项目根目录运行：

```bash
npm install
npm run build
```

构建完成后不要移动或删除项目中的 `dist/` 目录；Edge 将从这个目录读取扩展。

## 2. 以开发者模式加载

1. 在 Edge 地址栏打开 `edge://extensions`。
2. 打开页面左侧的“开发人员模式”（Developer mode）。
3. 选择“加载解压缩的扩展”（Load unpacked）。
4. 在文件选择器中选择本项目的 `dist/` 目录。
5. 确认扩展列表出现 **Day Start**，且没有错误提示。
6. 打开一个新标签页；页面应显示 Day Start，而不是 Edge 默认新标签页。

修改代码后重新运行 `npm run build`，再回到 `edge://extensions` 点击 Day Start 卡片上的“重新加载”。

## 3. 验证 Microsoft 账号同步

在需要同步的每台设备上：

1. 使用同一个 Microsoft 账号登录 Edge。
2. 打开 `edge://settings/profiles/sync`。
3. 确认总同步开关已开启，并确认“扩展”同步未被组织策略禁用。
4. 按上面的开发者模式步骤安装同一版本的 Day Start。
5. 在设备 A 新建一个测试书签并选择一套内置主题。
6. 等待 Edge 完成同步，然后在设备 B 打开新标签页；确认书签、分组、内置主题选择和设置出现。

Edge 同步存在调度延迟，不保证修改后立即出现在另一台设备。如果长时间没有更新，请确认两台设备的 Edge 同步页面均无错误，并尝试保持 Edge 打开数分钟。

## 同步范围

| 数据 | 是否通过 Edge 同步 |
| --- | --- |
| 书签、分组与排序 | 是 |
| 搜索与显示设置 | 是 |
| 内置主题选择 | 是 |
| 自定义背景图片内容 | 否，仅保存在上传图片的设备 |
| JSON 导出文件 | 否，由用户自行保管 |

内置主题图片属于扩展安装包，因此同步时只需要传递很小的主题标识。自定义背景图片不进入 `chrome.storage.sync`；在没有本地图片的设备上，Day Start 会回退到“极光”主题。需要跨设备迁移自定义图片时，请在每台设备分别上传。

## 卸载或恢复默认新标签页

打开 `edge://extensions`，关闭或移除 Day Start。再次打开新标签页即可恢复 Edge 默认页面。卸载扩展会删除其本地数据；如需保留书签，请先在设置中导出 JSON 备份。
