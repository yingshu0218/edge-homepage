# 书签图标、分组管理与主题细节设计

## 目标

在不增加同步负担的前提下提升启动页辨识度和管理体验：书签自动显示网站图标；分组操作集中到右侧管理抽屉；主题面板提供更清晰的选中反馈与完整外观控制。

## 书签图标

- 根据书签 URL 的站点来源生成 favicon 地址，优先请求站点根路径 `/favicon.ico`。
- 图标不进入 `AppSnapshot`，不占用 Microsoft/Edge 同步容量，也不触发数据迁移。
- 图片加载失败时隐藏损坏图片，显示书签标题的第一个可见字符；回退底色由站点主机名稳定计算，确保同一网站跨设备外观一致。
- 图标组件独立封装，书签卡片只消费 URL 和标题。
- Manifest 增加 favicon 所需的 `host_permissions`，允许扩展从 HTTP/HTTPS 网站加载图标。

## 分组管理

- 标签栏只负责切换分组，不再直接拖动，也不再显示零散的重命名和删除图标。
- 标签栏末尾提供“管理分组”按钮，打开右侧“分组管理”抽屉。
- 抽屉按当前顺序列出全部有效分组；每行显示名称、书签数量、重命名、删除和拖动手柄。
- 只有手柄启动排序，排序后立即通过现有 `persist` 保存与同步。
- 抽屉提供“新建分组”；新建和重命名使用抽屉内表单，不再使用 `window.prompt`。
- 删除分组时：空分组可直接确认删除；有书签时必须选择“移动到其他分组”或“一并删除”，并显示影响数量。至少保留一个分组。
- 抽屉沿用现有遮罩、Escape、焦点约束和焦点恢复行为。

## 主题细节

- 内置主题卡片显示名称、强调色圆点和明确的选中勾选标识。
- 主题抽屉增加“外观模式”选择：深色或浅色。
- 增加遮罩强度和背景模糊滑块，显示当前数值；调整后实时应用并保存。
- 自定义背景区域明确显示“当前使用自定义背景”或“当前使用内置主题”，上传处理期间禁用输入并显示状态。
- 主题选择同时应用主题推荐的外观模式和遮罩值；用户之后可继续覆盖这些参数。
- 设置抽屉不再重复显示遮罩与模糊控制，避免同一能力分散在两个位置。

## 数据与兼容

- 保持 `schemaVersion: 1` 和现有书签、分组、设置结构。
- favicon 为派生 UI，不保存图片、URL 或加载状态。
- 分组操作复用现有 `addGroup`、`editGroup`、`deleteGroup`、`deleteGroupAndBookmarks` 和 `reorderGroups`。
- 主题参数继续使用 `AppSettings.appearance`、`overlay`、`blur`、`themeId` 和 `useCustomBackground`。

## 测试与验收

- 图标测试覆盖 favicon 地址、失败回退、稳定颜色和无效 URL 防御。
- 分组管理测试覆盖列表计数、新建、重命名、手柄排序、最后一个分组保护以及两种非空删除方式。
- 主题测试覆盖选中标识、强调色、外观模式、参数调整和自定义背景状态。
- 应用测试覆盖分组抽屉生命周期、持久化调用、主题参数连接和启动页标签栏简化。
- 完整 Vitest、TypeScript、Vite 构建和 manifest 校验必须通过。

## 非目标

- 不支持用户上传或同步自定义书签图标。
- 不缓存第三方 favicon 到 IndexedDB。
- 不支持分组嵌套、图标或颜色配置。
- 不新增在线主题商店。
