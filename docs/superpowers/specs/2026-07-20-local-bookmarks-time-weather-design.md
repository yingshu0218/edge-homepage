# Day Start 本地书签、时间与天气设计

## 目标

本轮停止推进 Microsoft/Edge 跨设备同步，专注完善纯本地启动页体验。新增更适合中等数量书签的管理方式、设备本地时间设置，以及基于 Open-Meteo 的天气展示。产品继续保持“少量高频入口、背景氛围突出、主页信息克制”的定位，不加入待办事项。

## 范围

本轮包含：

- 将运行时持久化切换为纯本地存储，隐藏 Microsoft 同步状态与相关操作。
- 主页面限制每组直接展示的书签数量，并提供完整书签管理抽屉。
- 完善书签搜索、编辑、跨分组移动、多选批量移动和批量删除。
- 在顶栏显示设备本地时间，并提供时间显示设置。
- 在顶栏显示当前天气摘要，并提供天气详情抽屉。
- 支持手动搜索城市和可选的浏览器当前位置。
- 保留 JSON 导入导出作为手动备份与迁移方式。

本轮不包含：

- Microsoft、VPS、GitHub、Gitea 或其他跨设备同步。
- Edge/Chrome HTML 书签批量导入。
- 待办事项、日历或其他效率组件。
- 多时区时钟。

## 页面结构

采用已确认的极简顶栏方案：

- 顶栏显示产品标识、本地时间、当前天气摘要、主题入口和设置入口。
- 时间摘要显示当前时间；天气摘要显示天气图标与当前温度。
- 点击时间打开右侧时间详情抽屉；点击天气打开右侧天气详情抽屉。
- 主内容继续显示搜索框、当前分组和有限数量的书签卡片。
- 当当前分组书签数超过展示上限时，在书签区显示“查看全部（共 N 个）”。
- “查看全部”打开右侧全部书签管理抽屉，不在主页无限向下扩展。

各右侧抽屉互斥，同一时间只打开一个，沿用现有抽屉的关闭方式、焦点管理和窄屏适配。

## 书签展示与管理

### 主页面展示上限

设置中新增“每组显示数量”，可选择 `8`、`12` 或 `16`，默认 `8`。主页严格按当前分组排序取前 N 项，不增加另一套置顶状态。修改设置后立即更新页面并写入本地快照。

若书签数量超过上限，显示“查看全部（共 N 个）”；未超过时不显示该入口。空分组继续显示新增书签入口。

### 全部书签抽屉

抽屉默认展示当前分组全部书签，并提供：

- 按书签名称或网址进行不区分大小写的即时搜索。
- 编辑书签名称、网址和所属分组。
- 删除单个书签。
- 多选书签后批量移动到另一分组。
- 多选书签后批量删除，执行前显示包含数量的确认提示。
- 进入现有独立排序页面的入口。

搜索只过滤当前视图，不改变排序或持久化数据。编辑网址沿用现有 URL 规范化与校验规则。跨分组移动后，书签追加到目标分组末尾；源分组与目标分组的相对顺序保持稳定。

排序继续只在独立排序页面中完成，并使用专用拖动手柄，避免拖动、选择和编辑手势冲突。

## 时间

时间使用设备本地时区和系统时钟，不提供手动时区。

顶栏默认使用 24 小时制显示小时与分钟。时间详情抽屉显示完整日期、星期和当前时间，并提供：

- 12 小时制或 24 小时制。
- 是否显示秒。
- 是否在详情中显示完整日期和星期。

时间显示通过单一计时器对齐到秒或分钟边界更新；页面不可见时不进行无意义的高频刷新，恢复可见时立即校正。

## 天气

### 数据源

使用 Open-Meteo：

- Geocoding API 用于城市名称搜索和候选地点选择。
- Forecast API 使用经纬度获取当前、小时和每日天气。
- 不要求用户注册或配置 API Key。

扩展只请求 Open-Meteo 所需域名，并在清单中声明最小化的网络权限。天气描述和图标由 WMO weather code 在本地映射，不加载第三方图标资源。

### 地点选择

首次打开天气时提供两种方式：

1. 手动输入城市名称，从候选结果中选择明确的城市、行政区和国家。
2. 点击“使用当前位置”，届时才请求浏览器定位权限；不在页面加载时主动弹出授权。

定位成功后只保存解析后的经纬度、显示名称和时区信息，不保存持续定位历史。用户拒绝定位时保留手动搜索入口，并显示非阻断说明。

### 展示内容

顶栏显示天气图标和当前温度。天气详情抽屉显示：

- 城市名称、天气状态与数据更新时间。
- 当前温度、体感温度、当天最高/最低温。
- 当前或近期降水概率。
- 未来 12 小时的时间、图标、温度和降水概率。
- 未来 5 天的天气、最高/最低温和降水概率。
- 摄氏度/华氏度设置，默认摄氏度。
- 手动刷新和更换城市入口。

### 刷新、缓存与失败

- 有已选地点时，天气数据最多每 30 分钟自动刷新一次。
- 打开天气抽屉或扩展恢复可见时，只有缓存已过期才发起请求。
- 同一地点的并发刷新合并为一次请求。
- 成功响应经运行时校验后写入本地缓存，缓存不进入 JSON 导出。
- 断网、超时、限流或响应损坏时，优先展示最近一次成功缓存，并标注其更新时间和刷新失败状态。
- 从未成功加载且请求失败时，显示可重试的空状态，不影响书签、搜索、主题或时间功能。

## 本地存储与导入导出

应用运行时只使用本地存储：

- 停止读取和写入 `chrome.storage.sync`。
- 隐藏 Microsoft 标识、同步进度、同步错误和重置同步数据入口。
- 可见状态改为简洁的“数据保存在本机”，不暗示跨设备能力。
- 书签、分组、主题、搜索和显示设置继续保存在版本化的应用快照中。
- 自定义背景继续保存在本机图片存储中。
- 天气地点和显示单位进入应用设置；天气响应单独作为可丢弃缓存保存。

保留现有同步抽象与适配器源代码，但应用启动和持久化路径不实例化或调用 Microsoft 同步提供者，为未来 VPS 同步保留接口边界。

JSON 导出包含书签、分组、排序、主题、搜索及用户设置，不包含天气响应缓存、定位历史或自定义背景图片二进制。导入继续使用版本检查和数据校验；导入成功后只覆盖本地应用快照。

## 模块边界

- `bookmarks`：主页截断规则、全部书签抽屉、搜索、选择和批量操作。
- `time`：格式设置、本地时间格式化和可见性友好的计时更新。
- `weather`：地点搜索、定位、Open-Meteo 客户端、WMO 映射、缓存和天气抽屉。
- `storage`：本地快照、天气缓存和导入导出；不依赖具体同步实现。
- `newtab`：组合顶栏、主页和互斥抽屉，不承载天气解析或书签变换逻辑。

天气 API 响应在客户端边界转换为内部模型，界面组件不直接依赖第三方响应结构。书签批量操作以纯函数生成下一份快照，再通过统一本地持久化入口保存。

## 可访问性与响应式行为

- 时间和天气摘要使用原生按钮，提供明确的辅助技术标签。
- 抽屉打开后焦点进入标题或首个控件，关闭后返回触发按钮。
- 搜索结果数量、多选数量、天气加载和错误状态通过可感知文本表达，不只依赖颜色或图标。
- 窄屏下顶栏摘要保持单行短文本，抽屉占满可用宽度；小时预报允许在抽屉内部横向浏览。
- 遵循减少动态效果设置，天气图标不使用持续动画。

## 测试与验收

单元测试覆盖：

- 8/12/16 展示上限与“查看全部”条件。
- 书签名称和网址搜索、稳定跨组移动及批量删除。
- 12/24 小时制、秒和完整日期格式。
- WMO code 映射、温度单位转换、天气响应校验、30 分钟缓存有效期。
- 定位拒绝、天气请求失败、损坏响应及过期缓存回退。
- 应用运行时不读取或写入 `chrome.storage.sync`。

组件测试覆盖全部书签抽屉、批量操作确认、时间设置、城市候选选择、当前位置授权触发、天气加载/缓存/重试状态和抽屉互斥。

Edge 手工验收覆盖：重新加载扩展后本地数据保留；主页显示数量切换；大量书签仍保持简洁；时间与系统一致；城市搜索和当前位置均可用；断网后仍显示缓存；JSON 导出再导入可恢复业务设置；另一设备不会再被承诺或显示为已同步。

## 完成标准

- 主页面每组最多展示用户选定的 8、12 或 16 个书签。
- 用户可在独立抽屉中搜索、编辑、跨组移动和批量管理全部书签。
- 顶栏以极简方式显示本地时间和当前天气，并能进入对应详情抽屉。
- 天气在正常网络、定位拒绝、断网和 API 错误下均有明确且不阻断核心功能的状态。
- 所有业务数据默认仅保存在当前设备，产品界面不再呈现 Microsoft 同步能力。
- 自动化测试和正式构建通过，并完成 Edge 单设备手工验收。
