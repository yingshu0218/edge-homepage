# Day Start

Day Start 是一个面向 Microsoft Edge 的新标签页扩展。它提供可分组、可拖拽排序的自定义书签，六套内置图片主题、本地自定义背景、JSON 导入导出，以及基于 Edge 扩展同步存储的跨设备配置同步。

## 功能

- 替换 Edge 新标签页，支持搜索、网址直达与键盘操作
- 新建、编辑、删除书签，按分组浏览并拖拽排序
- 六套随扩展打包的主题；主题选择可同步
- 自定义背景保存在当前设备，避免占用同步存储配额
- 书签、分组、主题选择及设置通过 Microsoft Edge 配置文件同步
- JSON 备份的导出、替换导入和合并导入
- 分组重命名、删除（移动或一并删除书签）及拖拽排序

## 本地开发

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

验证生产构建：

```bash
npm test
npm run build
```

`dist/` 是可直接加载到 Edge 的扩展目录。完整步骤见 [Edge 安装与同步验证](docs/edge-installation.md)。

## 数据与同步边界

Day Start 以本地数据优先。Edge 登录并开启同步后，轻量配置通过 `chrome.storage.sync` 同步；自定义图片二进制数据和网站图标缓存不会进入 Microsoft 同步。若另一台设备选择了自定义背景但没有对应本地图片，页面会安全回退到“极光”主题。

同步写入会在写前估算替换后的 UTF-8 用量：超过 90 KiB 显示容量警告，超过 100 KiB 拒绝远端写入但保留本地数据。若同步分块损坏，扩展不会合并或覆盖本地快照，并会提供“重置同步数据”恢复入口。
