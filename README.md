# Day Start

Day Start 是一个面向 Microsoft Edge 的新标签页扩展。它提供带网站图标的分组书签、独立排序与分组管理抽屉、六套内置图片主题、本地自定义背景、JSON 导入导出，以及基于 Edge 扩展同步存储的跨设备配置同步。

## 功能

- 替换 Edge 新标签页，支持搜索、网址直达与键盘操作
- 新建、编辑、删除书签；网站图标加载失败时自动回退为首字母图标
- 在右侧“书签排序”抽屉中通过手柄调整当前分组的书签顺序
- 在右侧“分组管理”抽屉中新建、重命名、安全删除和排序分组
- 六套随扩展打包的主题，支持深浅模式、遮罩和背景模糊调节
- 自定义背景保存在当前设备，避免占用同步存储配额
- 书签、分组、主题选择及设置通过 Microsoft Edge 配置文件同步
- JSON 备份的导出、替换导入和合并导入
- 搜索引擎下拉选择，内置 Google、Bing、百度、DuckDuckGo、Brave、搜狗和 360 搜索

## v0.1.0 基线

当前版本面向开发者模式自用安装。自动化测试覆盖书签、分组、主题、导入导出和 Edge 同步适配器；正式构建输出在 `dist/`。发布前仍需在两台登录同一 Microsoft 账号并启用扩展同步的 Edge 设备上完成跨设备验收。

## 本地开发

需要 Node.js 20 或更高版本。普通网页预览不具备扩展专属的 `chrome.storage` API；完整功能请使用 `dist/` 在 Edge 中加载验证。

```bash
npm install
npm run dev
```

验证生产构建：

```bash
npm test
npm run build
```

`dist/` 是可直接加载到 Edge 的扩展目录。完整步骤见 [Edge 安装与同步验证](docs/edge-installation.md)。

## 数据与同步边界

Day Start 以本地数据优先。Edge 登录并开启同步后，轻量配置通过 `chrome.storage.sync` 同步；自定义图片二进制数据和网站图标缓存不会进入 Microsoft 同步。若另一台设备选择了自定义背景但没有对应本地图片，页面会安全回退到“极光”主题。

同步写入会在写前估算替换后的 UTF-8 用量：超过 90 KiB 显示容量警告，超过 100 KiB 拒绝远端写入但保留本地数据。若同步分块损坏，扩展不会合并或覆盖本地快照，并会提供“重置同步数据”恢复入口。
