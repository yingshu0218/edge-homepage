# Day Start

Day Start 是一个面向 Edge 的本地优先新标签页扩展。它提供分组书签、主题、自定义背景、设备本地时钟、天气和 JSON 备份迁移。首个商店版本不承诺跨设备自动同步，断网时除在线天气刷新外仍可正常使用。

## 功能

- 替换 Edge 新标签页，支持搜索、网址直达与键盘操作。
- 新建、编辑、删除书签；网站图标加载失败时自动回退为首字母图标。
- 每个分组可选择显示 8、12 或 16 个书签；超出的书签可在“管理书签”中查看。
- 完整书签管理器支持按名称或网址搜索、编辑、批量移动、批量删除和排序管理；分组也可新建、重命名、排序和安全删除。
- 六套内置图片主题，以及只保存在当前设备上的自定义背景。
- 顶栏时钟使用设备本地时间，可设置 12/24 小时制、秒数和完整日期。
- 城市天气由 Open-Meteo 提供，支持城市搜索、摄氏/华氏切换和用户主动请求当前位置。
- 版本化 JSON 备份支持导出、替换导入和合并导入，可用于设备之间的手动迁移；兼容的旧备份会在导入时迁移。

## 数据、网络与隐私

Day Start 的书签、分组和设置写入扩展本地存储；天气缓存、书签图标与自定义背景也只保存在当前设备。重新加载扩展或关闭 Edge 不会清除这些数据。卸载扩展通常会清除本地数据，因此仍建议先导出 JSON 备份。

扩展不使用浏览器配置文件的云端存储，不显示远程数据状态，也不会把 Day Start 数据传输到其他设备。需要迁移时，请在原设备的“设置”中导出 JSON 文件，安全地传到新设备后选择“替换现有数据”或“合并数据”导入。

天气功能声明了 Open-Meteo 和 BigDataCloud 的 API 主机权限：手动搜索城市时，Open-Meteo 会收到城市查询；选定城市、打开已配置天气或手动刷新时，Open-Meteo 会收到用于天气查询的坐标。只有点击“使用当前位置”后，Edge 才会显示定位授权请求；取得当前位置时，BigDataCloud 才会收到当前坐标以解析地点，拒绝授权不会影响城市搜索或其他功能。BigDataCloud 说明其免费客户端端点会观察请求 IP 和当前坐标，并使用匿名聚合的 IP 与坐标配对来改进 IP 地理定位。天气结果会在本机缓存 30 分钟；网络离线或刷新失败时，如有已缓存结果，页面会继续显示上次天气并提示刷新失败。概览卡片页脚会标明当前使用的数据来源。

Day Start 不会持续追踪位置，也不保存位置历史；不使用 API 密钥、分析、广告或账户。重新加载已解压缩的扩展后，Edge 可能会提示确认新增的 BigDataCloud 主机权限。

书签图标通过浏览器的扩展 favicon API 获取，并缓存在本机 IndexedDB 中。缓存图标会立即显示，每 7 天在后台更新一次；获取失败时保留旧图标，并在 24 小时后重试。没有可用图标时会在本地回退为首字母图标。

书签卡片会记录从启动页打开书签的次数，并显示最近 24 小时、7 天、30 天和添加后的累计打开次数。累计次数永久保留，滚动时间统计只保存最近 30 天的点击时间，并随书签数据同步。

## 本地开发

需要 Node.js 20 或更高版本。普通网页预览不具备扩展专属的 `chrome.storage` API；完整功能请使用 `dist/` 在 Edge 中加载验证。

```bash
npm install
npm run dev
```

验证生产构建：

```bash
npm test
npm run build
```

`dist/` 是可直接加载到 Edge 的扩展目录。加载、权限说明、离线天气和 JSON 迁移步骤见 [Edge 安装与本地数据验证](docs/edge-installation.md)。
