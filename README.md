# Day Start

Day Start 是一个面向 Edge 的本地优先新标签页扩展。它提供分组书签、主题、自定义背景、设备本地时钟、天气和 JSON 备份迁移；Day Start 数据始终保存在当前设备，不会自动传到其他设备。

## 功能

- 替换 Edge 新标签页，支持搜索、网址直达与键盘操作。
- 新建、编辑、删除书签；网站图标加载失败时自动回退为首字母图标。
- 每个分组可选择显示 8、12 或 16 个书签；超出的书签可在“管理书签”中查看。
- 完整书签管理器支持按名称或网址搜索、编辑、批量移动、批量删除和排序管理；分组也可新建、重命名、排序和安全删除。
- 六套内置图片主题，以及只保存在当前设备上的自定义背景。
- 顶栏时钟使用设备本地时间，可设置 12/24 小时制、秒数和完整日期。
- 城市天气由 Open-Meteo 提供，支持城市搜索、摄氏/华氏切换和用户主动请求当前位置。
- 版本化 JSON 备份支持导出、替换导入和合并导入，可用于设备之间的手动迁移；兼容的旧备份会在导入时迁移。

## 数据、网络与隐私

Day Start 的书签、分组、设置和天气缓存写入扩展本地存储；自定义背景写入当前设备的本地 IndexedDB。重新加载扩展或关闭 Edge 不会清除这些数据，但卸载扩展通常会清除其本地数据，因此请先导出 JSON 备份。

扩展不使用浏览器配置文件的云端存储，不显示远程数据状态，也不会把 Day Start 数据传输到其他设备。需要迁移时，请在原设备的“设置”中导出 JSON 文件，安全地传到新设备后选择“替换现有数据”或“合并数据”导入。

天气是唯一会请求外部服务的功能：输入城市名称时会请求 Open-Meteo 的地理编码服务；选定城市、打开已配置天气或手动刷新时会请求 Open-Meteo 的天气预报服务。点击“使用当前位置”后，Edge 才会显示定位授权请求；拒绝授权不会影响城市搜索或其他功能。天气结果会在本机缓存 30 分钟；网络离线或刷新失败时，如有已缓存结果，页面会继续显示上次天气并提示刷新失败。

## 本地开发

需要 Node.js 20 或更高版本。普通网页预览不具备扩展专属的 `chrome.storage` API；完整功能请使用 `dist/` 在 Edge 中加载验证。

```bash
npm install
npm run dev
```

验证生产构建：

```bash
npm test
npm run build
```

`dist/` 是可直接加载到 Edge 的扩展目录。加载、权限说明、离线天气和 JSON 迁移步骤见 [Edge 安装与本地数据验证](docs/edge-installation.md)。
